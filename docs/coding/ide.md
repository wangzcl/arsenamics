# 选择编辑器

显然，在开始写代码之前，你需要下载安装一个编辑器。在 Windows 上的记事本或 MacOS 上的 TextEdit 里写代码不是好的想法。许多现代的编辑器不仅能编辑文本文件，还能与代码解释器/编译器交互，实现自动补全，代码高亮等一系列便捷功能，它们有时也被称为集成开发环境（Integrated Development Environment, IDE）。

!!! question
    我该选择什么样的编辑器？

编辑器的选择很大程度上取决于你在写什么语言。对于有些语言（尤其是 MATLAB 等商业软件），自带的 IDE 可能就是最优解。如果你在用这类语言，并且很清楚自己需要什么样的编辑器，那么你可能不需要读这篇文章。

对于大多数读者，我们建议使用微软开发的 [Visual Studio Code](https://code.visualstudio.com/)（VS Code）。

## VS Code

在本文写作的2025年，VS Code 毫无疑问是专业开发者间最主流的编辑器，虽然在一部分学术领域还没有那么盛行。根据 Stack Overflow 论坛 2024 年的[调查](https://survey.stackoverflow.co/2024/technology#1-integrated-development-environment)，约 73.6% 的开发者使用 VS Code，超过第二名（Visual Studio）的两倍。

选择 VS Code 的理由在于：

- VS Code 功能相当全面通用，足以一站式应付多种编程语言的开发
- 免费，核心组件开源
- 有活跃的社区和丰富的插件生态，功能上快速跟进最新潮流（如 AI 编程）

一部分人对 VS Code 的印象是需要手动配置，学习曲线陡峭，所以会从一些更简单的编辑器开始（一些高校课程中也采用这种策略）。实际上，现在 VS Code 的配置已经相当简单，大多数时候只要点击下载几个插件就能使用。如果你预期自己要长期与代码打交道，与其用其他编辑器发现功能不足然后重新来过，不如开始就使用 VS Code 为将来的更多需求做准备。

在本项目的其他相关页面中，我们都会默认基于 VS Code 环境来操作。其他编辑器道理应该是相通的。

### 配置

这里我们选择性地给出一些配置 VS Code 的建议。

从[官网](https://code.visualstudio.com/)下载安装 VS Code 后，强烈建议花些时间，对照着软件界面阅读[官方文档](https://code.visualstudio.com/docs)，尤其是 Setup 和 Get started 部分。官方文档还会介绍如何根据不同编程语言进行设置（可能是最好的配置教程之一，比起大多数第三方教程更新，虽然可能对新手没那么友好）。在打开 VS Code 时，首页也会默认显示一些教程。

!!! note
    VS Code 自身已经接近开箱即用，建议一开始只进行最低限度的设置，熟练后再根据自己需求调整一些非必需项目，如界面布局、主题等。不需要每一步都按照官方设置操作。官方教程里有些步骤（如把 `code` 命令添加到 `$PATH` 中）完全是可选的。

VS Code 内需要配置的项目基本上只集中在两处：左下角齿轮里的“设置（settings）” 和左侧边栏中的“扩展（即插件，extensions）”。建议在进行设置前，先用 GitHub 账号登录，把用户设置同步到云端。大多数语言都需要扩展才能正常运行。选择和安装扩展时，请参考官方文档里关于编程语言的指南、编辑器里的推荐和扩展市场里的搜索结果。

在配置 VS Code 之外，你还需要安装特定语言的编译器/解释器才能让计算机理解和运行代码。
