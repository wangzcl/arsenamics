# Markdown

Markdown 是一个简单（轻量级）的文本标记语言。只需要在纯文本文件里加一点标注（如把想要变成斜体的文字两边用 `*` 围起来），把文件后缀改成 `.md`，支持 Markdown 的程序就能按标注的格式显示文本。

纯文本文件表现力有限，而 MS Word 之类的格式又太过复杂，引入了不必要的不确定性，而 Markdown 解决了这个问题。如果你只关心文本的结构（标题、章节、加粗强调、超链接等）而不太关心用什么字体、行距多少，那么 Markdown 可能对你有用。本项目的文本基本上就是用 Markdown 写成的。大多数成熟的开源项目也会有一个 Markdown 写成的 README 文件。

!!! note
    一般来说，能使用 Markdown 的地方都支持其**基本语法**。有些编辑器（如 Obsidian）和网站（如 GitHub）还或多或少支持一些**扩展语法**或**方言**，但具体细节上有所不同。
